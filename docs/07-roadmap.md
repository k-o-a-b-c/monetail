# 07 開発ロードマップ（レガシー完成 → 将来の再実装）

更新日: 2026-10-18。完了項目は現行コードとCI結果に基づく。残るマイルストーンは**提案**で、機能追加範囲や技術スタックの最終決定ではない。

## 方針

レガシー版の日常利用に必要な機能と計算の互換性を先に確定し、次世代版の設計・テストへ引き継ぐ。現段階ではSQLiteをD1へ変更しない。マスタメンテナンス画面はユーザー方針で作成を見送り、店舗登録なしでもレシートを入力できる構成を維持する。

## 仕様の判断と次の候補

[13 用語・意思決定](13-glossary-decisions.md)の各項目について、確定・実装済み・未決定を区別する。DDL受領、税端数、テスト／CI整備、外部キーの削除順、レシートNULL読込、小数割引率の読込修正は完了しており、再び未実装の前提で計画しない。

小数割引率の読込（LEG-005）はこの版で修正した。次の改修候補は**支払メモ一括保存のトランザクション（LEG-012）**。まず実SQLiteで途中失敗を再現し、必要な変更へ範囲を絞る。マスタ画面は引き続き作成を見送り、ポイントは採否の判断を先に行う。

D1への変更、未決定の認証・権限の先行実装、実DBへの未検証SQL適用、ソースの全面書換えは行わない。
