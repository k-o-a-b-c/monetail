# 03 金額・税・按分・残高の計算

現行の正本は[12 計算契約](12-calculation-contract.md)。2026-10-22に明細税率・Decimalと正確な分数の計算へ切り替えた。過去分も[41 コピー移行](41-detail-tax-copy-migration.md)で同じ方式にする。旧Double誤差は維持しない。

- 明細は`(単価 - 金額値引) × 数量`から、率値引をCeilingした額を引く。オーケーの割引は従来どおり金額を手入力する。
- 会計は分類をまたいで税率別に合算し、税額をレシートの切捨／四捨五入で丸める。対象外は別に加え、内税では差引額をそのまま合計する。
- 収支は値引後の符号で抽出し、同じ計算を独立に行う。
- 分類・個人別の参考額は正確な分数で按分し、税額と最後の円額を明示的に丸める。会計合計の代用にはしない。
- 残高推算は[21の日末・期間規則](21-end-of-day-balance.md)と既存の取引順序を維持し、新しい会計額を使用する。振替と登録残高の仕様は変えない。
