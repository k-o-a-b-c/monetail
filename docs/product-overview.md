# monetail — 製品概要

monetailは、**収入・支出、お金の移動、残高を記録し、人物・支払方法・科目などの観点から家計を把握する**ための家計簿アプリです。レシートを明細単位で管理し、誰に関係する支出か、どの支払方法を使ったかを区別して記録できます。

## 基本となる概念

| 概念 | 意味 |
| --- | --- |
| **家計簿** | 記録と管理の単位。家計簿ごとに人物・支払方法・科目・取引を管理する |
| **アカウント** | ログインして操作する利用者。複数の家計簿に参加でき、家計簿ごとに権限を持つ |
| **人物** | 家計簿内でお金の利用者・記録の対象となる人。アカウントとは別の概念で、対応付けは任意 |
| **支払方法** | 現金・口座など、お金の支払い元や移動元・移動先を表す単位。家計簿内の人物を所有者とする |
| **科目** | 収入・支出を分類する単位。家計簿ごとに管理する |

アカウントが家計簿に参加することと、家計簿内の人物として記録されることは別です。人物にアカウントが対応していなくても、その人物に関する家計の記録を扱えます。

## 主な機能

| 機能 | 概要 |
| --- | --- |
| **レシート** | 日付・店舗・支払方法・科目グループ・品目明細・対象人物などを記録する |
| **振替** | 支払方法の間で移動したお金を記録する |
| **残高・評価額** | 日付ごとに支払方法の残高・評価額を扱い、取引履歴から推算残高を求める |
| **支払メモ** | 支払方法ごとの確認日やメモを管理する |
| **集計・分析** | 科目別の収支、支払方法別の収支、残高の推移などを確認する |
| **マスタ管理** | 人物・支払方法・科目を管理する |
| **家計簿の共有** | 参加者の招待・管理と、家計簿ごとの閲覧者・編集者・管理者の権限を扱う |
