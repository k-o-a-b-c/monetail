# 12 現行の金額・税・参考集計契約

2026-10-22。[42 Windows版切替](42-detail-tax-application.md)の実装に対応する。Windowsの手動操作・実データ確認は[未完了テスト](../tests/README.md#未完了テストまとめて実施するもの)を参照。[切替前の契約](history/12-calculation-contract-before-detail-tax.md)は履歴として保持し、過去専用モードには使わない。

## 型・値引

単価・数量・金額値引・税率の整数保存は維持し、明細の率値引はDecimal。SQLiteではInvariantCultureの十進文字列をTEXT保存する。割引率の文字列は`Decimal.TryParse`（`NumberStyles.Float`・InvariantCulture）で変換し、書式不正・範囲超過を拒否する。小数2桁程度の利用を想定するが、2桁への制限・丸めは追加しない。極端に多桁・微小な値の扱いは標準のDecimal変換に委ねる。変換後の会計計算ではDouble変換を挟まない。

`B = (fee - discount_fee) × quantity`、`net = B - Ceiling(B × discount_rate / 100)`。1単位あたりの金額値引を先に引く。オーケーの値引額は引き続き手入力で、3/103等を自動適用しない。率値引をCeilingする業務ルールは変えない。

`ExactMoney`はDecimalの係数とスケールを使い、乗除算をBigIntegerの商・余りで正確に処理する。人数按分は`MoneyFraction`の整数分子・分母で保持し、1/3等を小数へ近似しない。グラフ用のDouble値を会計へ戻さない。

## 会計・収支

明細の確定した税設定を使い、課税額をレシート全体で税率値ごとに合算する。同率の別コードも合算し、分類で分けない。対象外は別合算。0%課税とはマスタの種別で区別する。

- 外税floor: 税額=`Floor(T × rate / 100)`、税込=`T + 税額`。
- 外税half_up: 同じ税額を0桁・AwayFromZeroで丸める。
- 内税: `net`をそのまま合計する。
- 全税率の税込と対象外を加え、最終値をInt32範囲で変換する。

floorは負方向への丸め。税額−0.5円は−1円、−10円は−10円のまま。half_upの負の中間値もゼロから遠い側へ丸める。

税額は抽出前のレシート全体で確定する。明細ごとの丸め前税額をいったん負方向へ切り捨て、確定税額との差の1円を小数部分の大きい順に配分する。同じ小数部分ならグループ順・明細順を優先する。負額・正負相殺にも同じ処理を使い、税率別の配分合計を確定税額へ一致させる。

収入は`net<0`、支出は`net>0`の明細へ配分済みの税込額を抽出して合算する。収入＋支出は会計合計と一致し、月次・年次も各レシートの確定額を合算する。`GetTotal`は画面の未確定税設定で計算でき、元Receiptの設定は変更しない。

| 例（外税floor） | 現行の正確な結果 |
| --- | ---: |
| 10%課税−100円＋対象外1,000円 | 合計890円・収入−110円・支出1,000円 |
| 10%課税−100円のみ | −110円（旧Doubleの−111円を修正） |
| 対象外10,000円の0.14%値引 | 値引14円・差引9,986円 |

過去分の表示・集計も同じ計算へ統一する。ただし`t_receipts.total`は仕様変更時の比較基準なので、コピー移行ではNULLを含む保存値・格納型を保持し、新計算値で上書きしない。構造変更に伴う更新版だけを進める。通常の登録・編集保存時に計算値を保存する既存動作は維持する。旧保存値・旧再計算値・新値は[41の監査記録](41-detail-tax-copy-migration.md)に残す。

## 参考集計・範囲超過

分類・個人別は従来の対象者一致条件（参照一致、完全一致／部分一致、対象者なし）を維持する。按分ありでは採用明細を割当人数で割り、0人は除外。選択人数を掛けない。

分類・対象者による抽出と人数割は、レシートの税額を明細へ配分した後に行う。分類別・明細別では税額を計算し直さず、配分済み税込額を合算する。人数割は税込額を正確な分数で保持し、最終参考円額だけfloor／half_upで丸める。例: 3明細の1/3円は正確に1円。10%・floorの−5円だけのレシートを2人で按分する場合は、確定税込−6円÷2人＝−3円となる。

同じレシートの10%・19円2明細は、floorなら確定税額3円を2円・1円に配分し、分類が異なっても税込21円＋20円＝41円となる。別レシートに19円ずつ記録した場合は各20円で合計40円となり、レシート間で税額を丸め直さない。

参考額は会計の代用にせず、旧参考額との差を許容する。`GroupCalculatedFee`・`DetailCalculatedFee`もレシートの配分済み税込額を使う。最終会計・収支・グループ／明細参考額のInt32超過は従来の警告と入力保持・表示復帰で扱う。残高推算の日時・順序・振替の扱いは維持する。
