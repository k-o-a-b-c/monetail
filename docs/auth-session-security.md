# 認証情報保存・セッション・HTTP保護

[← 43 認証設計の入口](43-passkey-authentication-design.md)

## 保存と移行

| 保存対象 | 契約 |
| --- | --- |
| Identity標準テーブル群 | 安定した認証ID、利用可否、パスキー、ロール等。パスワード・メールアドレスは必須にしない |
| `AspNetUsers.DisplayName` | アカウント自身の表示名。未登録はNULL、初回検証成功時に保存し、復旧時は維持 |
| `auth_account_creation_requests` | 要求ID・発行者ID・新規アカウントID・発行日時。人物コードを含めない |
| `auth_sessions` | セッションIDのハッシュ、認証ID、発行・固定期限・取消・直近確認日時。タイムゾーンは保存しない |
| `auth_enrollment_codes` | ハッシュと登録用途・認証ID・UTC期限・消費／取消状態。生コードなし |
| Data Protectionキー | コンテナ外の永続フォルダへ保存し、アプリ識別子を固定する。非rootアプリのアクセス権を整える |

認証ストアは人物テーブル・旧人物リンク・人物コードへのFKを持たない。新規DBの準備・再実行は[42](42-api-foundation.md#db移行登録復旧コマンド)、既存DBの一度きりのSQL移行と保存値保持は[58](ledger-core-transition.md#新規利用と既存dbの境界)を参照する。

## セッションとHTTPの境界

- パスキーによるログイン成功時の期限は、その時点から13日（312時間）経過後、ログイン時の端末の地域で次に迎える午前2時（DEC-034）。日本時間で10月1日20時なら10月15日2時、10月1日1時なら10月14日2時。312時間後が午前2時ちょうどなら翌日とする。
- ブラウザーの`Intl.DateTimeFormat().resolvedOptions().timeZone`で得るIANA地域IDをサーバーで検証し、ログインチャレンジにだけ結び付ける。未取得・不正・非対応は`TimeZoneInfo.Local`へ補完する。端末時計やUTCオフセットを時刻の根拠にしない。
- 夏時間で午前2時が欠落する日は切替直後の最初の有効時刻、重複する日は早い方を候補とし、312時間後以前なら翌日の候補へ進む。通常は13日超〜14日だが時差変更の影響は生じる。
- ログイン時にUTC期限を保存し、Cookieも同じ日時で失効させる。地域はセッション・Cookieへ保存しない。旅行・端末地域・サーバー地域変更で既存期限を再計算しない。要求時は台帳を照合し、期限以上なら定時バッチを待たず拒否する。
- 再確認は同じアカウント・セッションの`VerifiedAtUtc`だけを更新し、固定期限を延ばさない。通常操作も滑動延長しない。重要操作は直近5分未満かつ未来でない確認日時を要求する。残り1日の再ログイン案内は設けない。
- WebのCookieは`__Host-`、Secure・HttpOnly・SameSite=Lax・Path=/・Domainなし。Web画面へlocalStorageのトークンを追加しない。Windows版には[OAuthの正本](auth-windows-oauth.md)によるBearer認証を追加する。ログアウトは現在セッションだけ、全失効や鍵削除では全セッションを失効させる。
- 各保護要求でセッション・有効アカウント・最新ロールを検証する。人物コードを送って本人を切り替えず、XMLの利用者コード設定も採用しない。未認証・失効・利用停止は401、権限不足・重要操作の確認期限切れは403、認証DB障害は503。人物未対応を403にする経路は削除した。302転送しない。
- 同じHTTPSオリジンから配信し、POST・DELETE等は登録・ログイン・ログアウトもCSRFを検証する。資格情報付きの任意CORSを許可しない。本文64 KiB、認証更新を合わせてIPごと1分20回、待ち行列なし。GET一覧はこの更新枠を消費しない。
- チャレンジは5分・1回限り・ブラウザー／用途固定。再開始で置換し、再起動で未完了分を破棄する。再確認と鍵追加はアカウントID・開始セッションのハッシュでも固定する。Cookie・生コード・WebAuthn応答を通常ログに出さない。
- 将来の業務入力では、入力途中の失効でも画面に入力を保持し、再ログイン後に本人が確認して登録する。自動再送や別アカウントへの引継ぎはしない。ブラウザーストレージの永続化は前提にしない。 Windowsの人物編集での一時保持・再開条件は[58](ledger-persons.md#人物管理画面同じウィンドウ内で切替)を参照する。
